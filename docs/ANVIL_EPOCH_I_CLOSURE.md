# PROJECT ANVIL — Epoch I Closure

Status: **COMPLETE — FINAL EXECUTABLE BASELINE QUALIFIED**

This is the historical one-time transition record that closed the ANVIL-00…10 research epoch before the first owner-facing Physical Fabric Workbench design stage. It is not a live roadmap and does not supersede `.anvil/project-state.json` or `docs/CURRENT_HANDOFF.md`.

## Why Epoch I was closed

ANVIL-00…10 established a bounded capability chain from persistent authored matter through disposable rigid topology, local passive/active semantics, compliant response, transient activation and semantic re-lowering after one topology change.

After that chain, the highest-value next question was no longer automatically another isolated ANVIL-NN falsifier. The project therefore stopped primitive accumulation and prepared an owner-facing composition checkpoint: **Physical Fabric Workbench v0**.

Workbench is an integration/owner-value stage. It is not ANVIL-11 and does not create a new scientific capability claim merely by working.

## Next stage — Physical Fabric Workbench v0 / W0 Design Gate

W0 begins with design and adversarial comparison, not code.

Primary question:

> What is the smallest transparent owner-facing specimen that composes already accepted ANVIL behavior, lets the owner directly judge whether the stack begins to express useful Physical Fabric, and does not require new physical semantics or generic ontology merely to make the composition convenient?

W0 should compare at least two credible minimal specimens. One promising lead is:

`Matter → BEARING → TORQUE-PATCH/ACTIVATE → CUT → REBIND → fresh re-lowered action`

but it is not frozen scope. A simpler passive topology/rebind specimen remains a credible comparator.

If a candidate Workbench design requires a new authored identity model, new physical law, torque scaling contract, FUNCTION/Control/Surface ontology, generic `FabricRuntime` or hidden machine template, stop and separate that uncertainty into a scientific falsifier rather than solving it inside integration.

## Work classes after Epoch I

1. **experiment** — asks a new falsifiable scientific/semantic/physics question;
2. **foundation** — promotes or hardens a reusable boundary already supported by evidence, or neutral falsification infrastructure;
3. **integration** — composes accepted capabilities for owner/system evaluation; green integration is not automatically science;
4. **maintenance** — changes tooling/process/packaging/documentation while preserving accepted semantics.

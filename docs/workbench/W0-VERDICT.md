## Candidate decision

### A — passive topology / REBIND

**REJECT AS FIRST WORKBENCH SPECIMEN, RETAIN AS FALLBACK.**

Reason: semantically safe but owner information gain is too close to the existing ANVIL-03 browser gate.

### B — original active topology design

**REJECT AS ORIGINALLY PROPOSED.**

Reason: pre-CUT owner torque and arbitrary owner-selected CUT timing silently broaden the dynamic state entering the topology transaction beyond the frozen ANVIL-10 path.

### B0 — post-rebind activation

**ACCEPT.**

Reason: preserves the high-value topology/re-lowering story while keeping the actual CUT transaction inside the accepted moving fixture. Persistent authored TORQUE-PATCH meaning is visible before CUT, but no claim is made that an active compiled action or transient activation state crosses the transaction. After CUT, the same source meaning is re-lowered into a fresh action against the rebound BEARING/current bodies, the new runtime begins OFF, and a bounded owner-triggered activation demonstrates causal work through the new endpoint.

### C — compliance / resolution

**DEFER AS A SEPARATE POSSIBLE LATER SPECIMEN.**

Reason: valuable but tests a different owner intuition and must not be combined into B0 merely for feature richness.

## What changed during adversarial review

The adversarial review found a real flaw rather than simply confirming the initial proposal.

Removed from v0:

- pre-CUT torque activation;
- arbitrary pre-CUT free-running;
- arbitrary owner-selected CUT timing/state;
- generic OFF/ON cycling across arbitrary horizons;
- ambiguous `PHYSICAL` wording that could imply runtime representation is physical truth.

Added/strengthened:

- deterministic progression to a frozen **CUT READY** checkpoint;
- one accepted CUT transaction only;
- fresh post-CUT runtime/action starts OFF;
- bounded fixed post-CUT active observation window;
- explicit **AUTHORED MATTER / RUNTIME INTERPRETATION / BOTH** language;
- two-stage owner judgement: first-pass observation before technical reveal;
- explicit classification of **LEGIBLE BUT SCRIPTED** as useful evidence rather than implementation failure.

The correction is scientifically material to scope even though W0 itself contains no scientific experiment: it prevents integration UI freedom from becoming an accidental broader physics claim.
